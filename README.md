ABG XS Launcher

ABG XS Launcher is a customized Minecraft: Java Edition launcher for Android.

It is based on PojavLauncher and provides a familiar, lightweight launcher experience with custom ABG XS branding and improvements.

Features

- Minecraft Java Edition on Android
- Multiple Minecraft versions
- Fabric support
- Mod and resource-pack support
- Java runtime management
- Renderer selection
- Account and instance management
- Custom ABG XS interface and branding

Status

Actively developed and tested on Android.
